# Gestro Dashboard

Real-time monitoring dashboard for Gestro hand detection system.

## Features

- Live webcam detection visualization
- Real-time performance metrics
- WebSocket streaming
- Detection controls and settings
- Performance charts and analytics

## Tech Stack

- React 18
- TypeScript
- Axios for REST API
- WebSocket for real-time updates
- Chart.js for visualizations

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build

# Run tests
npm test
```

## Configuration

Set environment variables:

```
REACT_APP_API_URL=http://localhost:8000
REACT_APP_WS_URL=ws://localhost:8000
```
